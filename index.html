Cài đặt AutoTrack
Kết nối với Google Sheets để lưu data trên nhiều thiết bị
1
Tạo Google Spreadsheet mới
Mở sheets.new → tạo sheet trống. Copy ID từ URL:
docs.google.com/spreadsheets/d/SPREADSHEET_ID/edit
2
Tạo Apps Script
Trong Spreadsheet → Extensions → Apps Script → Xóa code cũ → Paste nội dung file Code.gs vào → Điền SHEET_ID → Save
3
Deploy Web App
Deploy → New deployment → Type: Web app → Execute as: Me → Who has access: Anyone → Deploy → Copy Web App URL
4
Paste URL vào đây
Dán Web App URL vào ô bên dưới rồi nhấn Kết nối
